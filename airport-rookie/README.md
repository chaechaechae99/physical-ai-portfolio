# 신입사원 공항 키우기

대기업 신입사원이 입구 앞 빈 땅에 공항을 짓고 키우며 10년 안에 회장까지 올라가는 도트 그래픽 경영 시뮬레이션.
게임 중간에 회사 규칙이 바뀌는 이벤트가 터진다.

## 실행

```
python main.py      # tkinter GUI 버전
python server.py    # 웹 버전 → 브라우저에서 http://localhost:8000
```

외부 라이브러리 없이 파이썬 3.10 이상이면 실행된다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `config.py` | 가격, 시간, 난이도, 직급, 이벤트 일정 등 밸런스 숫자 |
| `game_state.py` | 게임 엔진 (돈, 맵, 도로 연결, 구역 성장, 비행기 운항, 승진, 엔딩) |
| `rules.py` | 규칙 변경 이벤트 목록 |
| `sprites.py` | 도트 그래픽 (코드로 픽셀을 찍어서 만든다) |
| `save_data.py` | 다회차 기록 |
| `main.py`, `ui.py` | tkinter 화면 |
| `server.py`, `web/index.html` | 웹 서버와 브라우저 화면 |

## 게임 규칙 요약

- 활주로는 한 줄로 8칸 이상 이어야 비행기가 뜬다 (대형 여객기는 12칸).
- 격납고와 탑승동은 활주로 옆에만 지을 수 있다.
- 여객 터미널, 상업, 주차는 도로 옆에 구역을 칠하면 수요에 따라 건물이 자동으로 올라간다.
- 쉬움/보통: 2년 차에 1번, 3~7년 차에 1번 규칙이 바뀐다. 어려움: 2년 차부터 매달 확률로 바뀐다.
- 클리어하면 관제탑 → 고급 상업 구역 → 주차 타워가 차례로 해금된다.
