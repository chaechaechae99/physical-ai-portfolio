# Fortune Service 계획서

> 2030을 위한 사주 기반 운세 웹사이트 (공부용 프로젝트)
> 작성일: 2026-10-12

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | Fortune Service (가칭) |
| 형태 | 웹사이트 (모바일 우선 반응형) |
| 대상 | 2030 세대 (꿈해몽은 전 연령) |
| 목적 | 공부용 — 크롤링, 사주 계산, LLM 활용, 풀스택 웹 개발 경험 |
| 수익 모델 | 없음 |

### 핵심 아이디어
운세를 **🔮 진지 모드**와 **🎉 재미 모드** 두 갈래로 나눈다.
- 진지 모드: 생년월일·태어난 시간으로 **사주팔자를 계산**해 정통 운세를 보여준다.
- 재미 모드: 입력 없이 바로 즐기는 **꿈해몽 · 타로 · 로또 뽑기**와, 공유하기 좋은 **전생 · 미래 배우자** 결과 카드.

### 🔮 진지 모드

#### 1. 오늘의 운세 ☀️
- 오늘의 운세 점수 (0~100) + 한 줄 요약
- 총운 / 애정 / 일·학업 / 건강 항목별 짧은 해설
- 행운의 색상 · 숫자 · 방향 · 아이템
- 오늘 / 내일 선택

#### 2. 재물운 💰
- 오늘 / 이번 달 재물 흐름 점수 (0~100)
- 재물운 총평 + "오늘 하면 좋은 것 / 피할 것"
- 오행 분포 차트 (木火土金水)

#### 3. 사주 궁합 💞
- 나 + 상대방 사주 입력 (2명)
- 궁합 점수 + 관계 유형 한 줄 (예: "서로를 키워주는 상생 커플")
- 성격 · 연애 스타일 · 갈등 포인트 · 오래가는 팁
- 오행 상생/상극 비교 차트

#### 4. 주간 운세 📅
- 이번 주 월~일 요일별 운세 점수 그래프
- 요일별 한 줄 조언, 이번 주 베스트/주의 요일

#### 5. 월간 운세 🗓️
- 이번 달 총론 + 재물 / 애정 / 건강 / 일
- 이번 달 길일 · 주의일

#### 6. 신년 운세 🎍
- 올해 총론 + 1~12월 월별 운세 흐름 그래프
- 올해의 키워드 3개, 분야별 운세

#### 7. 평생 운세 ☯️
- 타고난 성격 · 적성 · 재물 그릇 · 연애/결혼관
- 10년 단위 대운 흐름 그래프 + 시기별 해설
- 사주팔자 표 + 오행 분포 상세 해설

---

### 🎉 재미 모드

#### 8. 꿈해몽 🌙 (핵심 기능)
- **전 연령 대상** 유입용 메인 기능, 사주 입력 없이 바로 이용
- 키워드 검색: "돼지 꿈", "이빨 빠지는 꿈" → 길몽/흉몽 뱃지 + 해석
- 카테고리 탐색: 동물 · 사람 · 자연 · 행동 · 사물 등 대분류 → 소분류
- 인기 꿈 TOP 10
- **AI 해몽**: 사전에 없는 꿈은 꿈 내용을 문장으로 쓰면 Claude가 해석
- 데이터: 꿈해몽 사이트의 카테고리 체계·키워드를 참고해 **자체 해몽 DB** 구축

#### 9. 오늘의 타로 🃏
- 카드 섞기 → 3장 선택 → 뒤집기 애니메이션
- 과거 · 현재 · 미래 해석 (메이저 아르카나 22장부터 시작)
- 질문 입력(선택): "오늘 고백해도 될까?" 같은 질문에 맞춘 해석

#### 10. 나의 전생 찾기 👑
- 사주 기반으로 "전생에 나는 조선의 ○○였다" 결과 카드
- 전생의 직업 · 성격 · 현생에 이어진 특징
- 결과 카드 이미지 저장 → SNS 공유

#### 11. 미래에 나는 누구랑 결혼했을까? 💍
- 사주의 배우자 자리(일지)·관성/재성 분석 기반
- 미래 배우자의 성격 키워드, 분위기, 직업 계열, 첫 만남 장소/시기 힌트
- 결과 카드 이미지 저장 → SNS 공유

#### 12. 로또 번호 뽑기 🎱
- 운세가 아닌 **순수 랜덤 뽑기 게임**
- 추첨기 공이 굴러가다 하나씩 튀어나오는 애니메이션
- 6개 번호 + 보너스 번호, 번호대별 공 색상 (실제 로또와 동일)
- 한 번에 1~5세트 뽑기, 마음에 드는 세트 저장(localStorage)
- "재미로만 즐기세요" 고지

### 개인 데이터 저장 방식 (결정)
- 생년월일 · 궁합 상대 · 꿈 일기는 **사용자 브라우저(localStorage)에만 저장** — 회원가입·서버 저장 없음, 다른 사람과 공유 안 됨
- 꿈 일기 **백업**: JSON 파일 내보내기 / 가져오기 (기기 변경 대비)
- (선택, 추후) 카카오·구글 로그인으로 기기 간 동기화 — 도입 시 개인정보 처리방침 필요

### 부가
- 결과 페이지 공유 링크
- 다크모드

## 4. 데이터 방식 (결정)

공부 목적과 저작권·서버 부하 문제를 고려해 **"크롤링은 참고용, 서비스는 자체 생성"** 방식으로 간다.

```
[1단계: 수집·분석]          [2단계: 자체 엔진]               [3단계: 서비스]
 Firecrawl 크롤러   →   사주 계산 엔진(만세력)    →   웹사이트
 (운세·꿈해몽 샘플)      + LLM 운세 문장 생성           (결과 캐싱)
       │                 + 자체 꿈해몽 DB
       └── 구조·문체 레퍼런스 ──┘
```

| 대상 | 방식 | 이유 |
|---|---|---|
| 운세 크롤링 | 신한라이프 운세 결과를 소량 수집 → **항목 구조·톤 분석, 사주 계산 정답셋** | 타 사이트 문장을 그대로 서비스하면 저작권·약관 문제 |
| 꿈해몽 크롤링 | 사주포럼 꿈해몽의 **카테고리 체계·꿈 키워드 목록** 수집 | 해몽 문장은 자체 작성(LLM 보조)으로 재구성 |
| 사주 계산 | 양력↔음력 변환, 천간·지지, 오행 분포, 십신, 대운을 직접 계산 | 사주 로직 공부의 핵심 |
| 운세 문장 | 계산된 사주 데이터를 Claude API에 넣어 생성 | 크롤링 의존 제거, LLM 활용 학습 |
| 타로 | 78장(우선 22장) 카드 의미 데이터 자체 작성 | 공개된 일반 상징 기반 |
| 캐싱 | (사주 + 날짜 + 운세 종류) 단위로 DB에 결과 저장 | 같은 요청에 같은 결과, API 비용 절약 |

> 검증: 자체 계산한 사주팔자(년·월·일·시주)를 크롤링 결과와 비교해 정확도 확인
> (예: 1990-01-01 午시 → 己巳 / 丙子 / 丙寅 / 甲午)

## 5. 기술 스택 (안)

| 영역 | 선택 | 비고 |
|---|---|---|
| 프론트 + 백엔드 | **Next.js (App Router) + TypeScript** | 하나의 프로젝트로 풀스택 |
| 스타일 | Tailwind CSS | 모바일 우선 |
| DB | SQLite + Prisma | 공부용으로 가볍게, 추후 Postgres 전환 가능 |
| 검색 | SQLite FTS (꿈해몽) | 키워드 검색 |
| 사주 계산 | 음력 변환 라이브러리 + 자체 구현 | 라이브러리는 4단계 레퍼런스에서 확정 |
| 운세 생성 | Claude API (Anthropic SDK) | 프롬프트에 사주 데이터 + 출력 JSON 스키마 |
| 크롤러 | Python + Firecrawl (`docs/crawl/`) | 기존 코드 재사용 |
| 차트 | Recharts 등 | 오행 분포, 주간/신년/대운 그래프 |
| 애니메이션 | Framer Motion 등 | 타로 뒤집기, 로또 추첨기 |
| 배포 | Vercel (선택) | 공부용이면 로컬만으로도 OK |

## 6. 개발 로드맵

| 단계 | 목표 | 산출물 | 완료 기준 |
|---|---|---|---|
| **M0. 준비** | 폴더 구조, 레퍼런스 정리 | 폴더 구조, `REFERENCES.md` | 구조 확정 |
| **M1. 데이터 수집** | 운세 샘플 10~20건, 꿈해몽 카테고리·키워드 수집 | `crawl/output/` | 운세 항목·꿈 카테고리 정리 문서 |
| **M2. 홈 + 재미 MVP** | 홈 화면(디자인), 로또 뽑기, 타로 | Next.js 페이지 | 입력 없는 기능 동작 |
| **M3. 꿈해몽** | 자체 해몽 DB + 검색 + 카테고리 + AI 해몽 | `lib/dream/` | 키워드 검색 → 해석 표시 |
| **M4. 사주 엔진** | 만세력 계산 모듈 | `lib/saju/` + 테스트 | 샘플 20건의 사주팔자가 크롤링 결과와 일치 |
| **M5. 오늘의 운세** | 사주 입력 + Claude 운세 생성 + 결과 화면 | `lib/fortune/` | **MVP 완성** |
| **M6. 2차 기능** | 재물운, 사주 궁합, 전생, 미래 배우자 + 공유 카드 | — | 결과 카드 이미지 저장 |
| **M7. 3차 기능** | 주간 · 월간 · 신년 · 평생 운세 + 그래프 | — | 기간별 흐름 그래프 |
| **M8. 마무리** | 캐싱, 다크모드, (선택) Vercel 배포 | — | 같은 입력 → 같은 결과 |

## 9. 주의사항

- 크롤링 데이터는 **로컬 학습·검증용**으로만 사용하고 외부에 공개하지 않는다.
- 타 사이트의 운세·해몽 **문장을 그대로 서비스에 쓰지 않는다** (구조·키워드만 참고).
- 크롤링은 소량·저빈도로 (서버 부하 방지).
- `.env`(API 키)는 절대 커밋하지 않는다 → `.gitignore` 필수.
- 운세는 오락용임을 화면에 고지한다.
