# 05강. 사주 계산 엔진

## 학습 목표
- 60갑자와 사주 4기둥(년·월·일·시주)을 계산한다
- 크롤링한 **정답셋으로 테스트**하며 구현한다
- 간이 엔진의 한계를 알고 라이브러리로 교체한다

---

## 1. 기초: 60갑자

천간 10개 × 지지 12개 → 최소공배수 60개 조합.

```ts
const GAN = "甲乙丙丁戊己庚辛壬癸";
const JI  = "子丑寅卯辰巳午未申酉戌亥";
const GANJI = Array.from({ length: 60 }, (_, i) => GAN[i % 10] + JI[i % 12]);
// GANJI[0] = 甲子, GANJI[55] = 己未
```

## 2. 일주 — 기준일에서 날짜 차이 세기

하루에 한 칸씩 돈다. 기준일 하나만 알면 된다.

```ts
// 기준: 2026-10-12 = 己未 (인덱스 55)
dayPillar = GANJI[mod(55 + (날짜 - 2026-10-12)일수, 60)]
```

정답셋 22건에 돌려보니 **22/22 일치**. 가장 단순하면서 가장 확실한 기둥.

## 3. 시주 — 일간에서 정해진다 (오서둔)

```ts
hourStem = mod((dayStem % 5) * 2 + hourBranch, 10)
```

**야자시(夜子, 23:31~24:00)** 는 다음 날 일주를 쓴다 — 정답셋에서 확인:
`1988-08-08 24시 → 丙申일 戊子시` (00시는 같은 날 乙未일 丙子시)

## 4. 년주·월주 — 절기가 경계다

- 년주는 1월 1일이 아니라 **입춘(2월 4일 무렵)** 에 바뀐다. 1990-01-01은 아직 己巳년 → **뱀띠**
- 월주는 매달 **절기**(입춘·경칩·청명…)에 바뀐다. 월간은 오호둔으로 계산

간이 엔진은 절기를 **고정 날짜**로 근사했다 → 절기 **당일** 출생이면 틀린다.

| 정답셋 | 년주 | 월주 | 일주 | 시주 |
|---|---|---|---|---|
| 간이 엔진 (양력 19건) | 18 | 17 | **19** | **19** |
| manseryeok (22건, 음력 포함) | **22** | **22** | **22** | **22** |

틀린 3건 = 2000-02-04 08시(입춘 전), 1995-03-06 10시(경칩 10:16 근처) — 모두 **절기 당일**.

## 5. 정답셋 테스트 주도 개발

```
crawl_answers.py ─▶ data/saju_answers.json (22건)
                          │
web/scripts/test-saju.mts ─▶ 기둥별 일치 수 출력 + 불일치 목록
```

```bash
npm run test:saju
# 년주 22/22  월주 22/22  일주 22/22  시주 22/22  대운수 21/22
```

> 경계 케이스를 정답셋에 **일부러** 넣었기 때문에 간이 엔진의 약점이 바로 드러났다.

## 6. 라이브러리 교체 — 앱은 그대로

```ts
// lib/saju/simple.ts
export function saju(p: Profile): Saju {
  try { return registered ? registered(p) : simpleSaju(p); }
  catch { return simpleSaju(p); }         // 라이브러리 실패 시 간이 엔진으로
}
// lib/saju/engine.ts — manseryeok을 감싸 같은 Saju 모양으로 반환 + registerEngine()
```

페이지 코드는 하나도 안 고치고 엔진만 바꿨다. **인터페이스를 고정하면 구현은 갈아끼울 수 있다.**

12지시 → 실제 시각 변환에서 고생한 점: 시의 중간값(午 12:30)을 넣으면 경칩 10:16 케이스가 틀렸다. **짝수 정시(巳 10:00)** 로 넣어야 두 경계 케이스가 모두 맞았다.

## 7. 남은 차이 1건 — 관례 차이

2000-02-04 22시(입춘 20분 후) 대운 시작 나이: 라이브러리 10세 vs 원문 사이트 1세. 계산 오류가 아니라 **관례 차이**라 억지로 맞추지 않고 기록만 남겼다.

## 정리
- 일주는 기준일 + 날짜 차이 mod 60
- 년·월주는 절기, 시주는 일간에서
- 경계 케이스를 넣은 정답셋이 엔진의 품질을 보장한다
- 인터페이스를 고정하고 구현을 교체한다
