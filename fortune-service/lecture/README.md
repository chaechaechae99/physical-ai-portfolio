## 한눈에 보는 흐름

```
① 크롤링          ② 계획서        ③ 구조·레퍼런스      ④ 프로토타입
Firecrawl/POST  →  PLAN.md     →  폴더 분리         →  HTML 1개 (artifact)
                                  REFERENCES.md        피드백 10회 반영
                                                            │
⑨ 배포            ⑧ 법적 체크      ⑦ 콘텐츠            ⑤⑥ 실제 사이트
GitHub Pages   ←  면책·출처     ←  꿈 513·타로·카드  ←  Next.js + 사주 엔진
(소스 비공개)                                           (정답셋 22/22)
```

## 최종 결과물

- **기능 15개** — 운세 7(오늘·재물·궁합·주간·월간·신년·평생) + 신비 8(꿈해몽·꿈 일기·타로·별자리·띠별·전생·배우자·로또)
- **사주 엔진** — 양력/음력/윤달 입력, 크롤링 정답셋 22건 4기둥 전부 일치
- **꿈해몽 513개** — 원문 유사도 검사를 통과한 자체 작성 문장 + 키워드 기반 해몽
- **배포** — 소스 저장소 비공개, 사이트 저장소만 공개

## 이 강의에서 배울 수 있는 것

1. "데이터를 긁어와서 그대로 쓰면 안 된다" — 수집과 서비스 데이터를 분리하는 법
2. 도메인 로직(사주)을 **정답셋으로 검증**하며 구현하는 법
3. 프로토타입으로 빠르게 합의하고 실제 코드로 옮기는 흐름
4. 여러 작업을 **파일 소유권을 나눠 병렬로** 진행하는 법
5. API 키 없이도 규칙 기반으로 "AI 같은" 기능을 만드는 법
