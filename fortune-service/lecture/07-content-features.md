# 07강. 콘텐츠 기능 구현

## 학습 목표
- 수집한 원문을 **저작권 안전하게 재작성**하는 파이프라인을 만든다
- API 키 없이 규칙 기반 "꿈 해몽"을 만든다
- 타로 카드 3장을 하나의 이야기로 엮는 종합 해설을 만든다
- Canvas로 공유용 이미지를 만든다

---

## 1. 꿈해몽 재작성 파이프라인

```
dreams.jsonl (원문 1,879)
   │ 대표 선정 (카테고리 round-robin, 짧은 제목 우선)
   ▼
in_0..3.json (50개씩) ──병렬 4개──▶ out_*.json  {c, t, l, d}
   │                                  카테고리·제목·길흉·해석
   ▼
유사도 검사: difflib.SequenceMatcher(원문, 재작성).ratio()
   │  > 0.5 → 버리거나 다시 쓰기
   ▼
data/dreams.json  (64 → 253 → 513개)
```

```python
ratio = difflib.SequenceMatcher(None, src["text"], out["d"]).ratio()
if ratio > 0.5:   # 원문과 너무 비슷 → 제외
    continue
```

| 회차 | 재작성 | 유사도 탈락 | 반영 |
|---|---|---|---|
| 1차 | 200 | 8 (제외) | 189 |
| 2차 | 261 | 28 (다시 씀, 전부 통과) | 260 |

> 0.5는 **우리가 정한 안전장치**지 법적 기준이 아니다. 핵심은 "의미(돼지꿈=재물)는 가져오되 문장은 새로".

## 2. 키워드 기반 해몽 (API 키 없이)

`lib/dream/interpret.ts`

```
입력 문장 ─▶ 상징 63개 매칭 (물→감정·재물, 이빨→걱정·관계, 뱀→인연·재물 …)
          ─▶ 행동 13개 (줍다, 잃다, 쫓기다, 날다 …)
          ─▶ 감정 6개 (무섭, 행복 …) — "무섭지 않고"처럼 부정되면 무시
          ─▶ 점수(0~100) + 길몽/보통/주의 + 종합 해몽 3~5문장 + 비슷한 꿈 3개
```

예시:
- "바다에서 커다란 물고기를 잡았는데 하나도 무섭지 않고 신났어요" → **87점 길몽** (바다·물고기 + 잡다 + 기쁨)
- "시험장에 늦어서 뛰어가다가 이가 빠졌어요. 너무 무서웠어요" → **23점 주의** (시험·이빨 + 무서움)

> 화면에 "키워드 기반 해몽"이라고 **정직하게 표시**한다. AI인 척하지 않는다.

## 3. 타로 종합 해설

"과거·현재·미래 한 줄이면 운세랑 다를 게 뭐야" → 카드마다 데이터를 늘리고 **조합 규칙**을 만들었다.

```ts
// data/tarot.json — 카드 22장
{ name, keywords:{up,rev}, upright, reversed, love, work, money, advice, tone:{up,rev} }
```

| 단계 | 규칙 |
|---|---|
| 주제 선택 | 오늘 전반 / 연애 / 일·학업 / 금전 (+ 자유 질문) |
| 정·역방향 | 약 30% 역방향 — 이미지 180° 회전, 해석·tone 변경 |
| 흐름 | tone 3개로 상승 / 하락 / 유지 / 반등 / 정점 판정 + 미니 그래프 |
| 공통 테마 | 2장 이상 같은 테마면 "전환기" 등 강조 |
| 질문 답 | 미래 카드 tone으로 한 줄 답 ("지금은 기다리는 편이 좋아요") |

한국어 조사 처리: 받침 유무로 `을/를`, `이/가`, `으로/로` 자동 선택 — 템플릿 문장이 어색하지 않게.

## 4. 결과 카드 이미지 (Canvas, 의존성 0)

`components/share/drawCard.ts`

- 1080×1920(스토리) / 1080×1080(피드)
- `document.fonts.ready` 기다린 뒤 페이지 폰트로 그리기
- `measureText`로 한글 줄바꿈, 넘치면 글자 크기 축소
- 저장: `canvas.toBlob` → `<a download>`
- 공유: `navigator.canShare({files})` 되면 공유 시트, 아니면 저장 + 링크 복사

## 5. 기타 신비 기능
- **별자리·띠별**: (별자리, 날짜) 시드로 문장 풀에서 선택 → 하루 동안 고정
- **전생**: 일간(10) × 띠(12)로 신분·시대 결정 + 해시로 희귀도("상위 13%")
- **로또**: 순수 랜덤. "운"이라고 부르지 않는다
- **꿈 일기**: localStorage + JSON 내보내기/가져오기(id로 중복 제거)

## 정리
- 재작성은 "의미 유지, 표현 새로" + 자동 유사도 검사
- 규칙 기반이어도 상징·행동·감정을 조합하면 그럴듯하다
- 데이터를 풍부하게(필드 추가) 하면 조합 해설이 가능해진다
