# 04강. HTML 프로토타입

## 학습 목표
- 단일 HTML 파일로 "눌러볼 수 있는" 견본을 빠르게 만든다
- 디자인 토큰으로 테마를 쉽게 바꾼다
- 피드백을 짧은 주기로 반영한다

---

## 1. 왜 프로토타입부터?

계획서만 보고는 판단이 어렵다 → "사이트를 줘볼래?" 한마디에 HTML 파일 하나로 만들었다.

- 프레임워크 없이 HTML + CSS + JS 한 파일
- 해시 라우팅(`#tarot`)으로 페이지 전환
- 타로 이미지는 base64로 파일 안에 내장 (~500KB)
- 링크 하나로 공유 (Claude artifact)

## 2. 피드백 반영 기록 (실제 순서)

| 피드백 | 반영 |
|---|---|
| "좌상단 홈 글자 빼" | 브레드크럼 제거 |
| "진지 모드 → 운세" | 섹션 이름 변경 |
| "꿈 검색하면 안 나와" | 예시 16 → 64개, 본문 검색 |
| "파란색은 신한 베낀 느낌" | 보라 → 하늘색 → 올블랙 → **새벽하늘(남색+하늘색)** |
| "타로에 이미지" | 퍼블릭 도메인 카드 22장 |
| "개발 예정 말고 채워줘" | 8개 기능 페이지 |
| "생년월일 넣어도 1990만 나와" | **헤더 입력칸 + 사이트 전체 동기화** |
| "과거·현재·미래 한 줄이면 운세랑 뭐가 달라" | **타로 종합 해설** |
| "올블랙 에바" | 일반/다크 모드 전환 |

> 교훈: "1990만 나와"는 예시 데이터를 쓴다는 걸 **미리 말하지 않아서** 생긴 혼란이다. 견본의 한계는 처음부터 명시하자.

## 3. 디자인 토큰 — 테마 변경을 한 곳에서

```css
:root {                       /* 일반 모드 */
  --bg:#FFFFFF; --ink:#13202E; --line:#DDE7F0;
  --primary:#1B3A5C;          /* 남색: 헤더, 큰 카드 */
  --accent:#4FA3E0;           /* 하늘색: 선택, 테두리 */
  --gold:#C9A24B;             /* 아이콘, 점수 링 */
}
:root[data-theme="dark"] {    /* 다크 모드 */
  --bg:#0D1724; --ink:#E8F0F7; …; color-scheme: dark;
}
```

모든 컴포넌트는 `var(--…)`만 쓴다 → 색을 4번 바꿔도 토큰만 고치면 됐다.

**대비(contrast) 체크**: 하늘색 작은 글씨는 흰 배경에서 안 보인다 → 작은 글씨용으로 한 톤 진한 `#2F7FBF` 따로 둠.

## 4. 레이아웃 참고 vs 베끼기

신한라이프 운세 페이지에서 **구조만** 가져왔다:
- 단색 헤더 + 섹션별 카드 그리드
- 대표 기능 = 큰 컬러 카드, 보조 기능 = 테두리 작은 카드

로고·색·문구는 전부 자체. (08강 참고)

## 5. 견본의 한계 표시
- "예시 결과" 라벨 → 계산이 붙은 뒤 "간이 계산 · 재미로 봐주세요"로 교체
- 예시 데이터는 화면에서 **예시임을 표시**

## 정리
- 프로토타입은 합의 도구다. 빠르게, 한 파일로
- 색은 토큰으로, 두 테마 모두 대비 확인
- 견본의 한계는 먼저 말한다
