# 운결 (fortune-service)

사주 운세 · 타로 · 꿈해몽을 한곳에서 보는 2030 운세 웹사이트 — **공부용 개인 프로젝트**

> 🌐 사이트: https://chaechaechae99.github.io/fortune-service-site/
> 📚 강의노트: [lecture/](lecture/README.md) — 크롤링부터 배포까지 10강

## 구성

| 폴더 | 내용 |
|---|---|
| `lecture/` | 강의노트 10강 (크롤링 → 기획 → 사주 엔진 → Next.js → 배포) |
| `PLAN.md` | 계획서 (기능, 데이터 방식, 로드맵, 진행 현황) |
| `REFERENCES.md` · `references/` | 레퍼런스 (만세력 라이브러리, 사주 이론, 타로 이미지) |
| `crawl/` | 데이터 수집 스크립트 (Python) — 수집 원문은 저장소에 포함하지 않음 |
| `data/` | 자체 작성 데이터 (꿈해몽 513개, 사주 정답셋) |
| `prototype/` | HTML 프로토타입 (파일 하나로 동작) |
| `web/` | 실제 사이트 (Next.js 15 + TypeScript + Tailwind) |

## 실행

```bash
cd web
npm install
npm run dev        # http://localhost:3000
npm run test:saju  # 사주 엔진 정답셋 테스트 (22/22)
```

## 기능

- **운세 (7)**: 오늘의 운세, 재물운, 사주 궁합, 주간, 월간, 신년, 평생 운세
- **신비 (8)**: 꿈해몽(키워드 해몽), 꿈 일기장, 오늘의 타로(종합 해설), 별자리, 띠별, 나의 전생, 미래 배우자, 로또 번호 뽑기
- 헤더 생년월일 입력(양력·음력·윤달) 하나로 전체 동기화, 일반/다크 모드, 결과 카드 이미지 저장

## 저작권 · 고지

- 운세·꿈해몽 문장은 직접 작성했으며, 외부 사이트 원문은 포함하지 않습니다.
- 타로 이미지: Rider-Waite(1909) 퍼블릭 도메인 · 사주 계산: manseryeok(MIT)
- 모든 결과는 재미를 위한 콘텐츠이며 전문적인 조언을 대신하지 않습니다.
