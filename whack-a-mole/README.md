# 🐹 두더지 잡기

30초 동안 튀어나오는 두더지를 잡는 웹게임입니다. HTML 파일 하나로 되어 있고, 설치할 것 없이 브라우저에서 바로 플레이할 수 있어요.

**▶ 플레이하기: https://chaechaechae99.github.io/whack-a-mole/**

## 게임 방법

- **시작!** 버튼을 누르면 30초 동안 게임이 진행돼요.
- 두더지를 클릭하거나 터치해서 잡아요. 키보드 숫자패드(1~9)로도 칠 수 있어요.
- 난이도는 쉬움 / 보통 / 어려움 세 가지예요. 어려울수록 두더지가 빨리, 많이 나와요.

### 두더지 종류

| 두더지 | 모습 | 점수 |
|---|---|---|
| 일반 두더지 | 갈색 | **+10** |
| 황금 두더지 | 노란색, 빨리 숨음 | **+30** |
| 세쌍둥이 두더지 | 머리 세 개 (닥트리오 스타일) | 머리마다 **+10**, 셋 다 잡으면 보너스 **+20** (총 50점) |
| 메롱 두더지 | 보라색, `> <` 눈, 혀 날름, "메롱~" 말풍선 | **-20** (잡으면 안 돼요! 콤보도 끊겨요) |

- 연속으로 잡으면 콤보가 쌓이고, 콤보 5마다 한 마리당 +5점 보너스가 붙어요.
- 두더지를 놓치면 콤보가 끊겨요. 메롱 두더지는 놓쳐도 괜찮아요.

## 랭킹

- 게임 중에는 왼쪽 패널에 **TOP 5**가 보이고, "1등까지 N점!", "현재 3등 페이스" 같은 목표가 실시간으로 바뀌어요.
- 게임이 끝났을 때 TOP 5에 들면 이름을 입력해 등록할 수 있어요(최대 10자).
- 기존 1등보다 높은 점수를 내면 **"👑 새로운 챔피언 탄생! 기존 1등 OO님을 N점 차이로 제쳤어요!"** 축하 메시지와 색종이가 나와요.
- 랭킹은 난이도별로 따로 저장돼요.

> ⚠️ 랭킹은 브라우저(localStorage)에만 저장돼요. 다른 기기나 다른 브라우저와는 공유되지 않아요. 모두가 같은 랭킹을 보려면 Firebase나 Supabase 같은 외부 DB가 필요해요.

## 개발 기록 (2026-10-07)

오늘 Claude Code와 함께 작업한 내용이에요.

1. **기본 게임 제작 및 배포**
   - 3×3 구멍에서 두더지가 나오는 게임을 `index.html` 하나로 만들었어요(CSS로 그린 두더지, 콤보, 난이도 3단계, 숫자패드 지원).
   - GitHub 저장소 `whack-a-mole`를 만들고 GitHub Pages로 배포했어요.
2. **랭킹 시스템 추가**
   - 게임이 끝나면 점수를 보여주고 이름을 입력하는 칸을 넣었어요.
   - 게임 중 왼쪽에 1~5등 점수와 "이 점수를 넘으면 1등" 목표 패널을 추가했어요.
   - 상단의 '최고 점수' 칸을 '콤보' 칸으로 바꿨어요.
3. **두더지 개편 및 축하 연출**
   - 검은 폭탄 두더지를 누가 봐도 잡으면 안 될 것 같은 **메롱 두더지**로 바꿨어요.
   - 머리 세 개를 하나씩 잡는 **세쌍둥이 두더지**를 추가했어요.
   - 1등을 제쳤을 때 나오는 **챔피언 축하 메시지와 색종이 효과**를 추가했어요.
